# 요구사항 명세서 — naive 모달 재현 토글 (데모 전용)

> 작성일: 2026-11-04 · 작업 폴더: `docs/plans/2026-11-04/naive-modal-demo/`

## 0. 요구사항 원문

- 원문: "3번 브랜치로 전환하고 하나씩 같이 읽어나가서 이문제들을 파악하고 서버 띄워서 시각적으로 이문제를 만날 수 있게 해보자"
- Q/A: 방식 → **데모 전용 naive 모달 + 토글**(라이브러리 무변경) / 재현 목록 → **바깥 판정 DOM contains, click으로 바깥 감지, ESC 전체 닫힘·Tab 탈출, 스크롤 잠금 카운트 없음** / 모드 auto

## 1. 목표·대상 (필수)

데모(`index.html`)에 "문제 재현" 토글 패널을 추가한다. 체크한 버그만 일부러 틀리게 동작하는 `demo/naive-modal.js`로 Portal 모달을 열어, 각 문제를 화면에서 직접 겪을 수 있게 한다. 체크가 하나도 없으면 라이브러리 `createModal`을 쓴다. 브랜치 `feat/modal-features`(PR #2)에 추가.

## 2. 경계·불변식 (필수)

- N0 토글 전부 해제 = 현재 데모 동작 그대로(라이브러리 `createModal`).
- 토글별 재현 증상(각각 단독으로 켰을 때):
  - N1 **DOM contains**: 모달 안 "메뉴 열기 → 메뉴 항목"을 누르면 모달이 닫힌다.
  - N2 **click으로 바깥 감지**: "Portal 모달 열기"를 누르는 즉시 모달이 닫힌다.
  - N3 **ESC 전체·Tab 탈출**: 중첩 모달에서 ESC 한 번에 전부 닫히고, Tab이 모달 뒤 페이지 요소로 빠져나간다.
  - N4 **카운트 없음**: 중첩 모달에서 위의 것을 닫으면 아래 모달이 열려 있는데도 배경이 스크롤된다.
- 데모 페이지가 세로로 스크롤 가능해야 N4가 보인다(스크롤 확인용 영역 추가).
- "Portal 모달 열기" 버튼의 `stopPropagation` 제거 — naive 코드에서 흔한 형태로 N2가 드러나게. 라이브러리 버전은 이 상태에서도 정상이어야 한다(pointerdown 설계의 근거).
